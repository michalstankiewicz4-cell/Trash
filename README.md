# Złomowisko (Trash)

Gra w przeglądarce (JS/HTML, Three.js r186 + Rapier): wysypisko z platformą i maszynami — piec na papier,
zgniatarka puszek, wielka zgniatarka metalu, piec indukcyjny z rynną i formami na sztabki, punkt skupu przy wyjściu.
Widok z oczu, przedmioty z fizyką (masa, opór na zgniecenie w 3 osiach), pojazd z chwytakiem.

- Gra: `index.html` · Podgląd modeli: `models.html`
- Uruchomienie lokalne: `python3 -m http.server` w katalogu repo, potem http://localhost:8000
- Strona: https://michalstankiewicz4-cell.github.io/Trash/
